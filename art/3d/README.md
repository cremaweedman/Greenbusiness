# GreenBusiness 3D Art Workspace

This directory contains source metadata and, when appropriate, canonical 3D masters for structural GreenBusiness art.

## Layout

```
inbound/
  tripo/
  meshy/
masters/
  slots/
  environment/
  props/
  upgrades/
exports/
  png/
specs/
```

Raw generated models belong in `inbound/`.

Approved, cleaned Blender sources belong in `masters/`.

Never treat inbound AI-generated meshes as runtime-ready.

See:
- `docs/art/3D_PRODUCTION_PIPELINE_V1.md`
- `docs/art/3D_ASSET_SOURCE_OF_TRUTH.md`
