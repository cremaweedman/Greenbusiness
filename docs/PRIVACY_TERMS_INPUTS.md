# GreenBusiness Privacy / Terms / Community Inputs

This file is an implementation input, not legal advice.

## Data inventory

Expected account data:
- email;
- display name;
- authentication/session metadata;
- gameplay state;
- economy/ledger events;
- social/friend/club relationships;
- purchase/entitlement records;
- notification preferences and encrypted push tokens;
- analytics and operational logs.

Do not store:
- plaintext passwords;
- raw refresh tokens;
- raw push tokens in logs;
- payment card data;
- unnecessary government identifiers.

## Retention starting point

Define and document before alpha:
- account data: while account is active plus a documented deletion window;
- revoked sessions: short security retention;
- analytics: bounded retention appropriate to product analysis;
- audit/economy/purchase ledgers: longer retention for fraud/accounting integrity;
- push tokens: delete when user removes device/account or provider marks token invalid.

## User controls

Before public launch provide:
- account deletion request path;
- export/access request path;
- notification preferences;
- privacy contact;
- Terms acceptance/version tracking when legal copy is finalized.

## Community rules inputs

Clubs/social features should prohibit:
- harassment/threats;
- illegal-market solicitation;
- attempts to exchange real-money value through game systems;
- impersonation;
- spam/automated abuse.

Current product intentionally excludes unrestricted chat and P2P trading, reducing moderation exposure.

## Store policy inputs

Before iOS/Android release:
- complete cannabis-content policy review;
- ensure gameplay remains fictional/abstract and non-instructional;
- validate age-rating requirements;
- review all store copy, screenshots and keywords;
- document refund/provider handling.

## IP checkpoint

Before naming/marketing spend:
- trademark search for final product name;
- domain/app-store availability;
- visual/logotype similarity review;
- retain provenance for AI-assisted art and commercial licenses.
