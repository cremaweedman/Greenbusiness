# VS-01 ART QA CHECKLIST

Use this checklist for every asset review.

## Functional
- [ ] Correct manifest ID
- [ ] Correct gameplay purpose
- [ ] State/function understandable without text
- [ ] Works at target runtime size

## Art direction
- [ ] Matches GreenBusiness Art Bible
- [ ] Original IP
- [ ] Not photoreal
- [ ] No cyberpunk/neon drift
- [ ] No excessive gold
- [ ] No cannabis-leaf branding
- [ ] No criminal/drug-use framing

## Technical
- [ ] Correct aspect ratio
- [ ] Correct canvas
- [ ] Correct alpha behavior
- [ ] No accidental background
- [ ] No unwanted text
- [ ] No logos/signatures/watermarks
- [ ] No obvious generation artifacts
- [ ] Filename follows convention
- [ ] Runtime size/compression acceptable

## Family consistency
- [ ] Camera matches sibling assets
- [ ] Lighting matches sibling assets
- [ ] Materials match sibling assets
- [ ] Scale matches sibling assets
- [ ] Anchor/padding matches sibling assets

## Accessibility
- [ ] Meaning is not color-only
- [ ] Readable in grayscale where state-critical
- [ ] Readable at 25% scale
- [ ] Sufficient foreground/background separation
