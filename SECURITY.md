# Security Policy

## Reporting

Do not open a public issue containing credentials, exploit steps against a live deployment, personal data, or unreleased security details.

For a private production deployment, configure a dedicated security contact before closed alpha and publish that contact in this file.

## Scope

High-priority reports include:
- authentication/session bypass;
- admin authorization bypass;
- economy or premium-currency duplication;
- purchase/reward replay;
- cross-account data access;
- remote code execution;
- secret/token disclosure.

## Supported state

Security fixes target the current `main` branch. Closed-alpha deployment should not proceed from older phase branches.
